# `dcr-mcp` Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Kubernetes-ready Go MCP server (`dcr-mcp`) using `urfave/cli/v3`, `modelcontextprotocol/go-sdk`, `hasura/go-graphql-client`, and 100% `fp-go/v2` + `fp-go-loom` functional pipelines for five dictyBase Stock Center GraphQL operations over Streamable HTTP.

**Architecture:** Three layers composed purely with `fp-go/v2` (`Option`, `Either`, `IO`, `IOEither`, state structs + lenses): (1) `internal/graphql` wraps `hasura/go-graphql-client` queries in `IOEither` pipelines; (2) `internal/tools` validates tool inputs purely (`Either`), executes GraphQL `IOEither` pipelines, and registers the 5 tools on `*mcp.Server`; (3) `internal/server` and root CLI wire `/mcp` Streamable HTTP + CORS + `/healthz` under the `start-server` (aliases `serve`, `start`) `urfave/cli/v3` subcommand.

**Tech Stack:** Go 1.26, `github.com/modelcontextprotocol/go-sdk/mcp`, `github.com/hasura/go-graphql-client`, `github.com/urfave/cli/v3`, `github.com/IBM/fp-go/v2`, `github.com/dictyBase/fp-go-loom`, `github.com/stretchr/testify`.

**Spec:** `docs/superpowers/specs/2026-10-19-dcr-mcp-design.md`

## Global Constraints

- Module: `github.com/dictybase/dcr-mcp`, Go 1.26.8.
- Allowlist monads only: `Option` (`O`), `Either` (`E`), `IO` (`IO`), `IOEither` (`IOE`).
- Zero bare `if` branching in functional code; use `O.FromPredicate`, `O.Fold`, `O.GetOrElse`, `P.Fold`, `MO.First`, `E.FromPredicate`, `IOE.ChainEitherK`.
- Never use `IOE.FromEither` on pure `Either` helpers; compose pure `Either` Kleislis into `IOEither` pipelines with `IOE.ChainEitherK`.
- `IOE.TryCatchError` callbacks must contain only the raw SDK call; error wrapping goes in `IOE.MapLeft`, projection goes in `IOE.Map`.
- All quality gates must pass: `pipelinecheck` (`Require`, `RequirePointFreeSeed`, `RequirePointFreeBranching`, `RequireTrivialDelegate`, `RequireNoIfErrInTryCatch`, `RequireNoNonRawTryCatchCallback`, `RequireSafePrintf`, `RequireNoRedundantFold`, `RequireNoHandRolledFileJoinInArrayMap`, `RequireBareIf`), `loomcheck.Require`, `golangci-lint fmt`, `golangci-lint run ./...`, `go test ./...`, and `gopls check -severity=hint`.

## Review Focus

1. **Whitespace-only queries (`"   "`) in `autocomplete_stocks` / `search_stocks` / `get_strain` / `get_plasmid` / `list_strains_with_phenotype`:** Trimming must precede length checks so `"   "` fails validation rather than passing `MinStrLen(3)`.
2. **Case-insensitive or omitted `entity` in `autocomplete_stocks` and `search_stocks`:** Empty string `""` defaults to `ALL`; `"strain"` / `"STRAIN"` normalizes to `STRAIN`; invalid values like `"GENE"` fail with a descriptive error.
3. **Out-of-range or omitted `limit` and `cursor`:** `limit == 0` applies tool-specific defaults (`5` for autocomplete, `50` for search, `10` for phenotype strains); negative or over-max limits (`> 50` for autocomplete, `> 100` for search/phenotype) fail validation; negative `cursor` fails validation.
4. **Null/empty GraphQL nested slices (`dbxrefs: null`, `phenotypes: []`, `parent: {"id":"","label":""}`):** Projection must normalize `nil` slices to non-nil empty slices `[]T{}` so MCP JSON serialization emits `[]` instead of `null`.
5. **Browser CORS preflight (`OPTIONS /mcp`) and custom MCP headers:** Web apps send `OPTIONS` preflight with `Content-Type`, `Accept`, `Mcp-Session-Id`, `MCP-Protocol-Version` and read `Mcp-Session-Id` from responses; CORS middleware must allow and expose these headers and short-circuit `OPTIONS` with `204 No Content`.
